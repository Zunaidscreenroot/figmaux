# Wireframe

Create low-fidelity, native editable Figma wireframes from requirements.

## Before creation
Identify:
- User
- User state
- Primary goal
- Business objective
- Funnel objective
- Primary CTA
- Secondary actions
- Required information
- Edge cases

## Process
Information Architecture -> Content hierarchy -> Component hierarchy -> Wireframe

## Figma rules
- Inspect and reuse existing components and variables.
- Use Auto Layout where appropriate.
- Use semantic layer names.
- Keep fidelity intentionally low.
- Avoid decorative styling unless required to communicate hierarchy.
- Do not replace the existing design system.
- Create a new exploration page/section unless instructed otherwise.
- Never overwrite the original screen by default.
