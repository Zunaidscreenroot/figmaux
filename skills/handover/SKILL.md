# Design Handover

Create structured handover documentation for product, design, business, and engineering stakeholders.

Include:
- Problem statement
- Target users and user states
- Business objective
- Funnel objective
- IA
- Key UX decisions
- Component and interaction requirements
- States and edge cases
- Accessibility requirements
- Analytics/KPI requirements
- Open questions
- Dependencies
- Design rationale

Separate design decisions from development implementation tasks unless the user explicitly requests engineering tasks.
